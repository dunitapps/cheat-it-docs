# CheatIt Support

If you need help with **CheatIt: Watch Notes & AI**, have a question, or want to report a bug, you can reach out using one of the options below.

## Contact
Email support: **contact@dunitapps.com**

## Bug reports and feature requests
You can also report issues or suggest improvements by creating an issue on GitHub.

Create an issue here:  
https://github.com/dunitapps/cheat-it-docs/issues

When reporting a problem, please include:
- Device type (iPhone or Apple Watch)
- iOS/watchOS version
- A brief description of what happened
